# Sources: The answer was in the folder: what plain code can verify about an agent run, and what it cannot

1. [From Confident Closing to Silent Failure: Characterizing False Success in LLM Agents](https://arxiv.org/abs/2606.09863). arXiv (Laksh Advani), 2026-06-01. (primary) Used for: re-read 2026-10-07 (abstract page plus the full HTML at https://arxiv.org/html/2606.09863v1): the best judge configuration reached AUROC 0.640 on tau2-bench and 0.537 on AppWorld, while an XGBoost classifier over TF-IDF bigram features reached 0.825 and 0.953; the operating point (10 percent flag rate), the 1.19 ms versus about 4,000 ms latency behind the 3,364 times figure, per-domain trajectory and failure counts, the 1,425 of 1,879 AppWorld split, the 0.69 cross-domain transfer AUROC and the paper's own 'triage signal, not an autonomous monitor' qualification
