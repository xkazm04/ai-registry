# Medium package: A fixture post

1. Open `story.html` in a browser, select all, copy.
2. Paste into a new Medium story.
3. Render each `../figures/NN-<name>.svg` to `figures/NN-<name>.png` at 2x with a headless browser (the renders are derived and not stored in the registry), then upload each where its figure sits.
4. Add the tags from `tags.txt`.

Nothing in this package is sent anywhere; the paste is a human act.
