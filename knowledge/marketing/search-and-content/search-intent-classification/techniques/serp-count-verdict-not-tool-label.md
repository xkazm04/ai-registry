# The results-page count is the verdict, not the tool's label

A keyword gets its intent from a search that somebody actually ran, in the target
country and language, whose top ten organic results were classified one by one by
what each page *is*, and whose count was written down next to the verdict. A
tool's intent label and a modifier word are both hints used to decide which
keywords to search first. Neither is ever the answer.

The reason is measured, not stylistic. The classification taxonomy's own 2002
author wrote that intent cannot be inferred with certainty from the query. A 2008
classifier built from query features reached 74% on hand-coded queries, and 82%
of its errors were money or brand queries called informational. A tool label built
partly from word markers inherits that error; a label built from the results page
is closer, but it is still a snapshot somebody else took on some day, for some
country, and the map is accountable for its own.

## Procedure

1. **Search the query as the buyer would** - the target market's engine
   locale, the target language, a clean session. A results page from the
   wrong country is the wrong verdict for every query on the map.
2. **Set the ads aside for a moment** and note whether they are present; they
   are evidence, counted separately.
3. **Classify each of the top ten organic results by what the page is.** A
   guide, how-to, forum thread, video, question page: informational. A service,
   product, pricing, booking page or a business homepage: transactional. A
   comparison, best-of, review, roundup: comparison. A map placement or a
   business-profile card: local. The page's subject is irrelevant; a service
   page *about* costs is a service page.
4. **Count, and record the count**, not only the verdict: "7 of 10 are cost
   guides and forum threads". A count can be re-run and disputed; a label
   cannot.
5. **Apply the threshold** the map has agreed on, and label it as convention
   in the same breath. Six of ten is a common internal rule; it has no
   documented source anywhere and every published method uses unquantified
   language - dominant, most, many. A count that reaches no group's threshold
   is *mixed*, which is a real verdict with its own handling.
6. **Note the page's non-result evidence**: ads, a map pack, a featured answer
   or people-also-ask block, shopping results, a video pack. Each shifts the
   reading and each is written down.
7. **Record where the tool's label disagreed.** The disagreements are usually
   few and usually the expensive commercial terms; the list is the report's
   most useful paragraph.

## Decision rules

- When a tool's label and the counted page disagree, the page wins, because
  the page is the engine's published decision and the label is an inference
  about it.
- When a query has not been searched, it has no verdict - it may carry a
  provisional label marked as such, and no page is planned against it,
  because a page built on a guess is the most expensive way to run the
  search.
- When the threshold is stated to a client, it is stated as the team's rule,
  never as best practice, because presenting a convention as documented
  behaviour is the domain's most reproduced error.
- When the results page is from a different country or language than the
  business's market, the search is re-run, because the engine's verdict is
  per market and a map built on the wrong market's page is wrong throughout.
- When the count is close to the threshold on either side, the reading falls
  to the mixed-page and error-direction techniques rather than to rounding.

## What counts as "what the page is"

The classification is of the page type, not of the phrase in the title. A
product listing titled "How much does a kitchen cost" is transactional. A forum
thread titled "best accountant in the city" is informational. A business's own
homepage ranking for a generic query is transactional even if it says nothing
about the query. When a single result is genuinely both - a service page with a
long guide above the fold - classify it by where the call to action sits, and
say it was a judgement call.

## When NOT to use

- On a brand query that is not the business's own. The verdict is navigational
  and nothing is built; counting the page is wasted effort.
- As a substitute for the who-is-typing test. A page can count transactional
  and still be typed mostly by peers; the count answers "what ranks", not "who
  searches".
- To settle cluster membership. Whether two queries share a page is a
  different question with its own overlap test in the architecture subject.
- When the search cannot be run in the target market. A count from the wrong
  market is worse than an honest "not yet verified", because it looks
  finished.
