# Node: a closed three-class vocabulary with a stored-over-derived precedence

In the politicas money layer the taxonomy is already built the way the technique
describes, which is why this application is a hunt for a gap rather than a change.

## What the tree already does

One module (`features/money/reviewTypes.ts`) owns the closed list, the marker tables
and the single heuristic; the three offline case-loop scripts import it instead of
carrying copies. A resolver prefers a stored class over the derived guess, always
computes the guess so a disagreement stays visible and counted, and treats an
unrecognised stored value as absent. Copy names the provenance ("classified by the
pipeline"), headline money sums the attributable partition only, and steward money
renders on its own labeled side.

## The seam hunted, and what it showed

The claim tested: an unclassifiable tie is held out of class-based scoring rather than
given a class. The heuristic returns one of three classes for every input. A role that
matches neither the owner nor the board list (an empty role, a proxy, a liquidator) at
a company with no public marker falls to the supervisory class, and a company whose
name merely contains a short public marker is read as public, which also yields the
supervisory class. The default points away from accusation, so no person is accused by
the fall-through, and the derived origin is disclosed on every surface. But the
vocabulary has no explicit unknown, so the fall-through is a stated class rather than a
held-out tie, and the rendered caption describes a supervisory seat that nothing
established. Closing it needs a fourth value across the persisted edge props and some
thirty consumers, and the live graph carrying the role strings was not available to
count how many ties it would touch.

## Result

Registry-only, unmeasurable. No project change: widening a closed vocabulary that is
written onto graph edges, on the strength of a gap whose frequency is unknown, is the
finer-than-decisions structure the technique warns against. The three-class core, the
single module and the stored-over-derived precedence held.

Return condition: when the live graph is at hand, count ties whose role matches
neither list at a non-public-marker company; if they are more than a handful, add an
explicit unknown class that scoring and headline sums skip and the surface labels
"role not classified".
