# Laws — civic intelligence

Cross-cutting invariants of accountability work. Techniques cite these by anchor; they
are not subjects and get no folder. In this domain a wrong number is a product failure
and an uncited claim can defame — the laws exist because each was violated once and the
violation was measured.

## <a id="deterministic-code-owns-numbers"></a>Deterministic code owns every number

Every count, score, sum and rank is computed by reviewable deterministic code. A
language model may name, summarize and interpret — it never authors a figure, and any
numeric claim in generated prose must re-derive from the store or it does not render.

## <a id="missing-is-not-zero"></a>Missing is not zero

An absent value is a different fact from a measured zero. Rendering "0 speeches" for a
person whose speech data was never ingested is a fabricated claim. Every metric carries
its coverage; "not measured" and "not applicable" are first-class states, and nothing
missing ever loses a comparison.

## <a id="disclose-never-repair"></a>Disclose, never repair

Bad source data — an impossible date, a broken row, a header drift — is suppressed and
counted, never silently corrected. A repaired value is an invented value. The reader is
told what was withheld and why; the source keeps the blame.

## <a id="lead-not-finding"></a>A machine result is a lead, never a finding

Automated matches, web research, model verdicts and tripwires produce candidates for
human review. Coincidence in time or registry is a fact; substantive connection requires
human verification and until then must not be asserted anywhere. Machine review is not
human review, and the copy must say which one happened.

## <a id="every-cap-ships-its-population"></a>Every cap ships its population

A top-N list, a truncated read, or a sampled check states the size of what it was drawn
from. A capped corpus yields a floor, not a total; a silent truncation reads as
"everything" when it is not.

## <a id="one-definition-one-import"></a>One definition, imported everywhere

A rule that exists twice will drift, and in this domain every measured drift favored a
named person or firm. Thresholds, weights, vocabularies and formulas live in exactly
one place and are imported by every consumer — a restated literal is a future lie.

## <a id="non-partisan-symmetry"></a>Non-partisan symmetry

The method covers the whole population or covers nothing — a shortlist is an editorial
act. Absence of a conflict is a finding with equal claim to surface; scandals are
neither manufactured nor softened, across all parties identically.

## <a id="provenance-or-nothing"></a>Provenance or it does not ship

A number that cannot cite its source does not render. Every published claim carries a
permanent machine-checkable address, the formula reference that produced it, and its
gate state; primary registries outrank media; the method itself is published so the
reader can disagree with the method rather than the data.

## <a id="incident-anchored-doctrine"></a>Doctrine is anchored to its incident

A rule is recorded with the measured failure that produced it — date, counts, what was
published wrongly and for how long. A rule with its incident attached resists erosion;
a rule stated as a principle invites re-litigation. When a rule keeps being violated,
stop restating it and give it an observable output.
