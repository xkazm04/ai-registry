# Headless replay against the rules

The named concern: a rule that reads tracked input needs a regression test that runs without
a device, and that test is only worth anything if it runs the rule the game runs.

## When an input rule must be regression-tested without a device, feed recorded samples to the shipped rule code, because a test double proves only the double

The replay drives the same rule path the live game uses, from the sample stream onward, with
no rendering and no sensor. Determinism of the run itself is owned by the deterministic
headless timestep technique; this technique only requires that the replay use it. The
expected outcome of each clip is written down by a person who watched it, not derived from
the rule's own output on that clip.

## When a replay diverges from the live session it recorded, find the input-path difference before changing any rule, because the divergence is a finding

Compare what the live game saw with what the replay fed it: sample order, timestamps, held
samples, dropped frames, confidence. A replay that cannot reproduce its own session is not
yet evidence about the rule. Record the cause, and fix the replay path or the recording
before judging the rule.

## When wiring recorded input into an automated gate, bind the verdict to the clips and the rules revision, and place it on the evidence ladder

The gate output names the clips read and the rules revision judged. A replay pass is
headless evidence about the rules. It is reported as that, per tiers of truth, and never as
device evidence. A gate that has no clips for a rule reports the rule as unmeasured, not as
passing.

## Decision rules

- **When a rule has no clip that exercises its failure path, add one** before trusting the
  replay for that rule.
- **When the replay passes and a person finds a regression, add the person's session to the
  corpus** and record the miss. That is the raw data for the evidence gate this subject owes.
- **When the expected outcome was generated by running the rule, the test is circular.**
  Relabel it a snapshot, not a check.

## When not to use it

Not for judging feel, comfort or the sensor's behaviour. Those need a person on the device.
