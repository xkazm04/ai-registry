# Laws — media generation

Cross-cutting invariants of the craft. Techniques cite these by anchor; they are not
subjects and get no folder. Each law is stated once, here, and holds across every
subject in the bundle.

## <a id="causality-over-sequence"></a>Causality over sequence

Between any two adjacent beats of a factual narrative you must be able to say "but" or
"therefore". If the only honest connector is "and then", the beats have no causal
relationship and what you have is a list, not a story. The same facts arranged causally
give the viewer a reason to stay; arranged sequentially they give a reason to leave.
Every structural choice — engine, act architecture, frame order — inherits this test.

## <a id="checkability-routes-the-pixel"></a>Checkability routes the pixel

If a viewer could check an element against a fact, deterministic code must draw it. If
it only has to feel right, a model may. Charts, exact values, and labels are drawn and
composited; atmosphere and illustrative scenes are generated. A generated glyph is not
a nicer glyph — it is an unusable one.

## <a id="output-never-outruns-evidence"></a>Output never outruns evidence

A rendered artifact may never be more precise, more certain, or more causal than the
fact behind it. A crisp axis is a precision claim; an arrow is a causal claim; a chart
launders confidence unless the confidence propagates into the drawing. Every figure on
screen must trace to a sourced fact, and the fact's grade caps the rendering.

## <a id="refusal-is-a-state"></a>Refusal is a state, not an error

Generative providers refuse, and a refusal is a routing decision: re-route to another
provider or surface it honestly — never blind-retry the same request, and never let a
refusal masquerade as an empty success. No elimination is silent; the trail of who
declined and why is part of the output.

## <a id="edit-do-not-regenerate"></a>Edit, do not regenerate

Once a creator has reviewed work, feedback is answered with the smallest set of edits —
never a regeneration. A regenerated artifact voids every review, gate, and verification
computed against the version it silently replaced, even when it is "better". Touch what
the notes are about; leave everything else byte-identical.

## <a id="style-is-restated-not-remembered"></a>Style is restated, not remembered

Visual consistency across many generation calls comes from restating the full style
contract on every call. Reference images alone measurably drift within a single batch;
there is no short form, and no call may opt out of the style half of its prompt.

## <a id="unmeasured-is-not-pass"></a>Unmeasured is not pass

A quality gate may never report pass for something it did not check. "Unmeasured" is a
first-class verdict, distinct from pass and fail, and enforcement coverage — what
fraction of the promise is actually checked — is reported alongside the verdict. Craft
parameters ship only with measurements behind them; an impression is not a number.

## <a id="cost-per-usable-output"></a>Cost per usable output

Generation economics are computed over usable outputs, not renders. A cheaper render
that fails the brief more often is the more expensive plate; price per usable unit
inverts price per call often enough that the naive metric misroutes real money.
