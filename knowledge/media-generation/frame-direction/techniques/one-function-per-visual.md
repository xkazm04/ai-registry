# One function per visual

**A visual carries exactly one function. A beat that needs two is two
beats.** This is a splitting rule, not a minimalism aesthetic: when a single
beat genuinely demands both a reveal and the mechanism that earns it, the
correct move is never to cram both onto one frame — it is to split the beat,
because the beat was doing two jobs in the argument and the picture merely
exposed it.

## Why the rule is structural

The rule is deliberately the same shape as narrative craft's one law: an
"and then" between beats is a defect meaning the beats have no causal
relation; **two functions on one visual is a defect meaning one beat is doing
two jobs.** The visual layer is where this defect becomes detectable, because
functions are discrete and countable where prose is elastic. A sentence can
smuggle a turn and its mechanism past a reader in one breath; a frame that
must both withhold-then-deliver *and* diagram a process cannot hide that it
is two obligations.

In practice the rule fires on real material and each firing improves the beat
list. The canonical case: a turning-point sentence that both reverses an
established picture *and* holds it against a second established motif is one
sentence and two obligations — split it, let the first frame continue and
break the established line, and let the second frame compose the two threads
together. The most important image in a cut is often exactly such a
continuation, and it only works because each half does one thing.

## The frame-local corollaries

The same economy governs within a single frame:

- **One idea per plate.** Two competing mechanisms in one generated image
  read as clutter and the viewer resolves neither. If the subject description
  contains "while also showing", it is two plates.
- **One move per frame.** A push in *and* a pan *and* a reveal is three
  moves, and a viewer listening to a sentence resolves none of them. Motion
  authoring inherits the function's singularity.
- **Elements must each assert something.** Geometry that cannot state what it
  claims is decoration, and decoration on an arguing frame is a second,
  mumbled function.

## Decision rules

- When a beat's natural picture wants two functions, **split the beat**, not
  the frame. The split point is where the first obligation completes: the
  turn, then what the turn exposes.
- When two candidate functions describe the same picture (a reveal vs a
  state-change at a turn), choose by continuity: a **reveal introduces**
  something unseen; a **state-change modifies** something already
  established. If the motif exists, it is a state-change; asking for a reveal
  of a known image wastes the withholding.
- When the pressure to double up comes from time ("we only have four seconds
  here"), the answer is still a split — into more stills under the same
  narration, or into a rewritten beat — never a composite frame. Screen time
  is the script's problem; function integrity is the director's.

## When not to use this

Do not apply the rule to *layers*: a frame legitimately carries a plate, code-
drawn elements, and texts at once — those are one function realised across
layers, not multiple functions. And do not confuse function-singularity with
sparseness quotas: an evidence frame with five discrete exhibits is one
function ("the delivered list, in the flesh") with cardinality five, and is
correct. The rule counts jobs, not objects.
