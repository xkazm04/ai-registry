# Process: two script-composing studios, neither has a series, so neither has a seam

The seam hunt was chosen to falsify "a narration tool must already hold the two
declared components of a voice somewhere". A caught outcome would be a place where a
fixed opening, a fixed close or a list of permitted imagery is written into a prompt as
prose and then regenerated per script. The result was the opposite: nothing owns the
decision at all.

## What the two trees do

- **Studio with a script phase (long-form, per-project).** The close is a composed beat
  with the label "reframe, not summary", generated fresh per script and checked by a
  verdict step. That is the technique's second rule held by construction: the reframe is
  never conflated with a signature line. There is no fixed opening or sign-off slot, no
  profile object that could carry one, and no analogy list: the grep for bookend,
  catchphrase, cold open and reference world returns only the sign-off of a phase
  workflow (a different sense of the word) and the forbidden-figure rule of the gate (a
  factual constraint, not an imagery domain).
- **Data-video studio.** Scripts are written per use case for one narrator; there is no
  channel identity, so no series for a bookend to repeat across. A generation-rules
  schema recognises an ending card by name (a render-side concern) and a board-loop
  brief mentions physical metaphors as a visual idea, not a verbal reference world.

## Three cases walked under A (as is) and B (declared profile)

1. A long-form script about a monetary mechanism: A picks whatever analogy the model
   reaches for; B restricts it to declared domains and validates the forbidden list
   against the slots needing an analogy. Prediction: B changes the analogy only when
   the creator has declared a world, and no such declaration can exist today.
2. A second episode of the same project: A varies the opening line per script; B
   interpolates a stored literal. This is the only case with a visible difference, and
   it requires a project with a repeating series, which neither tree has.
3. A creator with no bookends: both policies leave the slots empty, which is the
   technique's own decision rule. Equivalent.

Falsified if a project's accepted scripts show repeated verbatim openings or closings
(then the series exists and the slot is owed). Not changed in either tree; a profile
field with no consumer would be the manufactured structure the technique warns about.

## Return condition

When either studio grows a creator profile (the voice-profile technique's object) or a
second episode per channel, extract bookends by exact match across accepted scripts and
declare the reference world with the creator; the licensed-degradation check then needs
a script-gate probe per analogy slot.
