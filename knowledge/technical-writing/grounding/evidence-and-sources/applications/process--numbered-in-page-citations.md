# Process: twenty-three numbered sources, the article's own measurement as source one

Witness: the two-round writing contest described in the `article-structure` application
(round two judged on 2026-10-05). Entry files are local run output; this records what the
winning entry's page and research log show, read on 2026-10-05. Every public URL below was
listed in that log; the ones this bundle relies on directly were re-opened on 2026-10-05.

## The finding

Two owner review points: tables built on a previous-generation tokenizer's data were "not
very relevant nowadays", and "not all variants work with sources". The host's amendment
made the second operational: numbered inline citations linking to a sources list at the end;
each entry with title, publisher, date and URL; every figure caption naming its source
numbers; every number in the text traceable; the research log kept in step with the page.

## How the winning revision realized it

- **Twenty-three numbered sources**, each in the log's table with title and publisher, the
  page's own date (or "read 2026-10-05" for undated pages), what the page contributed, and a
  type column (primary standard, primary docs, primary paper, own measurement, secondary).
  Five were new in round two; three were marked as counter-evidence and one as a limit on
  the thesis.
- **Source [1] is the article's own measurement**: eight experiments run on 2026-10-05,
  with the operating system, runtime and library versions, the exact download commands for
  the parallel corpus and each tokenizer file (including two ungated mirrors substituted
  for gated canonical copies, with the substitution stated), the counting rule, and the raw
  totals per language per tokenizer before any ratio.
- **A claims-to-sources map** in the log: one line per figure, table or quoted number,
  naming the experiment or source number.
- **Sources opened and not used**, with the reason: a pricing page dropped because no
  published tokenizer existed to multiply its price by; a model card superseded by the
  measured vocabulary size; a vendor page that returned HTTP 400.
- **Currency handled by replacement**: every comparison re-based on current tokenizers
  measured that day; the previous-generation vocabulary survives only as a grey history
  column and one sentence.
- **Inference labelled**: the remark that hidden reasoning tokens may be billed at
  English rates is marked in the page as an inference; the cache timeline figure's arrival
  times are captioned as an illustration.

## What this witness does and does not show

It shows the full apparatus is producible by a drafting agent within one revision and keeps
the page auditable: a reviewer can trace any number to a source or an experiment. It does
not show that readers use the citations, and the agent's own report that every link was
opened is a claim in the log, not something this application re-verified link by link.
