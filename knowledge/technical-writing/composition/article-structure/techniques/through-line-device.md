# Through-line device

The concern: knowledge is organized by taxonomy, attention by consequence. A post that
walks the topic's taxonomy (definitions, then causes, then costs, then mitigations) reads as
a reference page, and every section can be skipped without losing the next. **Follow one
concrete object, usually the opening scene's, through every section, so each section
answers "what happens to this next".**

## How the device works

The opening scene introduces an object with a surprising number. Each later section takes
the same object one step further through the system the post explains: the message is
split into tokens, then priced, then packed into a context window, then cached, then
evaluated. The reader is never asked to switch context to a new example, and the
mechanism under discussion is always applied to something they have already seen. The
section's own new example, if it needs one, is introduced as a contrast to the
through-line object, not as a replacement for it.

The device also builds the close. Because the object went through every section, the
closing chapter can restate the post's findings as facts about it (the message cost so
many times as much in one language, missed the cache on this path, kept or lost quality by
this measure, each with the number the body established), which is
the most compact recap a post can have and the return to the opening that the reader has
been waiting for
([the opening promises, the close settles](../../../_laws.md#the-opening-promises-the-close-settles)).

## Procedure

1. List the sections. For each, write one line: what happens to the object here, and
   what number it produces.
2. A section with no line is either the wrong section for this post or needs a second
   object introduced as an explicit contrast. Decide which before drafting.
3. Mark each section's line where it lands in the draft (a figure that shows the object,
   a sentence that measures it). A reviewer can then trace the object from the opening to
   the close in one pass.
4. In the close, state the object's final account in numbers already established above.

## Decision rules

- **When a section needs a different example to make its point, keep the object and add
  the example as a contrast.** Replacing the object mid-post breaks the thread; contrasting
  against it strengthens it.
- **When the object cannot reach a section at all, that section probably belongs to
  another post.** The through-line is a scope test as well as a reading aid.
- **Do not force a narrative onto a mechanism that has none.** If the object only appears
  in a decorative first sentence of each section, the device has become a mannerism; cut
  those sentences and keep the object where it does work.
- **An analogy is not a through-line.** A sustained metaphor (the tax collector, the
  rubber stamp) costs the reader a translation step in every section and strains as the
  mechanism gets specific. A real object needs no translation.

## When not to use it

Comparative reviews of several independent systems, where each section is legitimately a
peer and the reader wants to jump between them; there the structure is a designed
comparison table plus parallel sections, and the through-line is the comparison axis
rather than an object.
