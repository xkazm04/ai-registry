# Lessons - reconcile

Append-only reflection lane. One entry per run that taught something, newest last.
Format: `## <version used> - <YYYY-MM-DD> - <scope>` followed by `- ` bullets.

Seeded from the lane's first campaign (software-engineering waves 1-7, llm-observability
wave N1, recruiting wave N2, cycles through N2-a) - the runs that existed before this
skill did, directed from session prompts. The brief (`docs/reconcile-brief.md`) carries
the contract those runs earned; this file carries what the DIRECTOR learned running it.

## pre-1.0 - 2026-08-24 - the campaign that preceded the skill

- **The best documents come from hints held loosely.** The strongest wave applications
  were a hint REFUTED with the binding retained (a register answering five states with
  one byte-identical body) and a worker who switched techniques mid-run on evidence.
  A hint written as a certainty produces confirmation; written as a starting point it
  produces findings.
- **Executed evidence found what reading never would.** Every upstream-reportable bug
  of the campaign (six across two bundles) came from running the claim: a harnessed
  pagination traversal, five exit-code cases through a real decision function, twelve
  live register queries hashed for byte-identity, a regulation's arithmetic worked
  over a real published audit table. Reading the same code found the shape; running
  it found the defect.
- **Workers correct the director, and the contract should let them.** A dispatch
  stamped `verified_on` a day ahead; all four class-B/C workers independently wrote
  the true resolution date and flagged the mismatch. The frontmatter block in the
  prompt is a template, not an order - the worker holds the fact.
- **A technique can be wrong-as-written, and only execution shows it.** Two cycle
  edits were disproofs of a technique's own sentence (a cursor column that loses rows
  under the technique's own prescribed order; a mod-N wording that loses sample
  nesting). Sightings converge at two; a measured disproof lands alone. Keeping the
  two lanes distinct is what keeps cycles small.
- **Class B/C evidence is real evidence.** A specification's own published digest
  command, a regulation's prescribed procedure over a published table, a register's
  raw responses saved and hashed - all of it spot-checkable by the director, one pin
  re-fetched live. The lane crossed from repositories to standards and registers with
  no contract change beyond what the brief already specified.
- **Connectedness is per-device; absence of a local consumer is not absence of a
  consumer.** The brief first ranked two bundles last for having "no connected
  project" - the operator then confirmed consumers exist on other devices. The
  projects map describes one machine. Unknown is not zero, applied to the fleet
  itself; ask the operator before down-ranking a bundle for missing demand.
- **Windows clones fail in two specific ways** - parallel shallow clones finishing
  with an empty git index (repair: `git reset --mixed HEAD`), and deep sample trees
  aborting checkout on path length (repair: targeted `git checkout --`, report what
  stayed unrestorable). Both cost a worker mid-run before they were named here.
- **The shipping word belongs to the operator.** Nine local commits carried a
  recorded "pull request owed at push time"; the operator discharged it by
  instructing a direct ship to the default branch. The obligation rule worked
  exactly as designed - owed at push time, resolved by a human at push time - and
  the skill encodes it rather than a hard branch rule.
