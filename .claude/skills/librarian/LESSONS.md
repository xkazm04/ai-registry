# Lessons - librarian

Append-only reflection lane. One entry per run that taught something, newest last.
Format: `## <version used> - <YYYY-MM-DD> - <scope>` followed by `- ` bullets.

This file exists because a sweep noticed its absence: deepen, forge and intake each
carried one, and the skill whose whole job is making other lanes evolve had no lane of
its own. Step 7's "reflect" now has an artifact to land in.

## 1.0 - 2026-08-23 - full-corpus sweep after the reconcile campaign

- **A flat ranking is a sweep result, not a sweep failure.** After a week in which the
  use_when class was closed corpus-wide, seven reconcile waves cleared 29 second-stack
  debts, and five cycles moved the technique and law layers, no subject scored above 5
  points - the residue was uniform never-swept (3) plus single-stack (2). The correct
  output was a report and zero dispatches. Dry is a result; the temptation to
  manufacture a worklist at that moment is exactly what the standing rule exists for.
- **The instrument's spot-check must target frontmatter, not prose.** The first
  witness-count verification grepped `verified_against` bare and matched the pin
  EXPLANATION sentence the reconcile applications carry. `^verified_against:` matched
  the real 40. A spot-check that can match commentary about the field verifies
  nothing.
- **The shared checkout changes what "the branch rule" means mid-session.** The sweep
  found itself on `main` because a parallel session merged the working branch during
  the campaign. With an interactive operator present, no push occurring, and a sibling
  session mid-flight on the same checkout, switching branches would strand the
  sibling's next commit; the sweep committed locally and recorded the PR obligation as
  owed at push time. An unattended scheduler gets no such judgment call - it must
  branch first, and this entry is the reminder to build that in.
- **The reconcile lane's residue defines the next campaign, and it is not in this
  bundle.** Single-stack is now the only structural debt class corpus-wide: 97
  subjects across seven bundles, but the external-reconcile lane has only ever run
  against software-engineering. For civic, grant and game bundles the "world-class
  counterpart tree" is a dataset, a standards body, or a rulebook rather than a
  repository - extending the lane there is a design question for its own sitting, not
  a dispatch from this one.
- **Watch the lanes converge on the vault.** During this sweep's window the vault
  gained a sources ledger from /research, run-id misattributions from a harvest's
  domain-note rewrite (corrected with a dated marker), and one subject note that a
  close-out regenerated over a sibling lane's note (recovered from git, merged, and
  "append, never regenerate" became a standing rule). Three lanes writing one vault
  is the design working - and the vault's integrity rules are what make it survivable.
