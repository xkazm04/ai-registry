## Six new techniques

- **`table/filtering`** — closes an asymmetry, not a topic. Sorting and pagination each
  had a *contract* technique beside `client-server-split`'s *placement* technique;
  filtering had placement and no contract. Its content is not regime-dependent: the
  predicate has two states — what the controls display and what the rows were produced
  under — and every derived artifact reads the second. Named for its breach: an export
  built from the controls, a file whose contents the user never reviewed.
- **`quality-gates/match-the-resolved-artifact`** — consolidates FOUR leads that are one
  mechanism: the bytes a matcher reads are not the thing the rule is about. Config
  shadowing, comment-satisfied matchers, stale fingerprints and a raw NUL byte all share
  the property that no liveness signal can see them, because the violation count stays
  zero and correct-looking for the whole dead period.
- **`motion/continuity-across-change`** — built around the distinction the source tree
  makes and the lead did not: a shared layout id matches two nodes and animates the
  picture; it does not preserve scroll anchoring, selection or focus.
- **`test-harness/pin-the-call-not-the-name`** and **`test-harness/assert-through-the-reader`**
  — needle choice and the false-red direction; and asserting through whatever actually
  parses the output rather than through a substring of it.
- **`cross-provider-benchmark-operations/axes-and-caveats-live-at-the-surface`** — one file
  carrying two leads that are the input and output halves of one rule: a new axis must
  reach the machine-readable contract, and the branch written first becomes the headline.

## Eight published rules that were wrong

- `async-ui-states/state-model` said an unstarted region collapses into loading. It does
  not, where a prerequisite chain the server already holds means no request should ever be
  issued. A fifth input upstream of the four makes `FAILED -> SETTLED-EMPTY` *unreachable*
  rather than guarded.
- `motion/react--preset-vocabulary` was teaching a **false library fact**, repeating a code
  comment that the animation library's global reduce switch "snaps EVERY animation
  (opacity included)". Read in the installed package in that very tree, reduction applies
  only to a position-class key set. Generalised into the technique: a reduce switch is
  scoped a second time, to the properties it counts as motion — worse than an engine gap,
  because the switch is present and reads as total coverage.
- `semantic-level-selection` said "normalize through one shared function". Too strong —
  consolidating on it would have broken the code. One entity needs two equalities when the
  surface asks two questions of it. The law forbids *unowned* plurality, not plurality.
- `invisible-differences` said "the rendering surface owns this, entirely and alone". False
  wherever a comparison has no reader: where a fold decides a stored row's identity, the
  kernel being *correct* that the bytes differ is the defect.
- `feed-retention` said a rollup outliving its rows is computed *before* the reap.
  Insufficient: a reaper that deletes at scale retries, and a fold written outside the
  transaction survives the rollback and double-counts.
- `graded-case-difficulty` said to degrade an unknown grade "on the way in". Right for an
  import, a defect for a stated write — a tree applying it at the write boundary accepted
  eight cases on a rung that does not exist, with a 200, and reported a phantom bucket.
- `os-escalation` said focus-awareness is mandatory. Not universally satisfiable: a message
  composed on a server and pushed to a webhook cannot observe attention at all.
- `canvas-graph`'s golden path listed as retired three things a read-only renderer still
  owes — the transform authority, the arrival policy, and every direct-manipulation
  mechanic. Rewritten to "every mechanic that changes structure".

**One rule survived with a different reason.** `status-color-mapping` justified merging

**And once the corpus was behind a tree.** `graded-case-difficulty` offered hand-grading,
