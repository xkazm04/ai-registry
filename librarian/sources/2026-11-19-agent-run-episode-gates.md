## The cluster's answer: which calls the agent makes alone

Both reports state it, and the lander's read agrees.

- **The agent decides alone:** breaking an approved story into clips, with the count set by duration and
  seams placed on beats once that rule is in its brief; reference sheets, keyframes and every prompt;
  pricing shots in advance; judging a shot against a rubric with a must-pass criterion; checking that a
  shot conforms to the brief; cutting a shot it cannot fix; applying a named fix to the named clip.
- **No person needed, but a mechanical bound must exist:** an attempt and spend cap per shot (the
  corpus holds it; G's run lacked it) and an output size bound on every local render (the corpus lacks
  it; A21, A22).
- **A person decides:** the premise; plan approval before any credit; each voice, heard on the first
  slice before anything extends from it; performance taste; re-spending on shots already approved; and
  whether the story reads to someone who did not make it (one voice, A3).
