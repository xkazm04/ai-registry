## Memory lane: which arm is this?

The V3 open build is **LLM extraction at write, never rewritten, plus hybrid retrieval**
(semantic + keyword + entity boost). The ladder has no arm of that shape. Every
distilling arm on it also consolidates, and the one arm with no rewrite ("verbatim +
hybrid retrieval, no model at write", 0.87 / 5 stale) runs no model at write. The nearest
priors bracket it. The source's own hosted numbers land where the lane's claim 1 predicts
for a store that keeps everything: **contradiction resolution is its weakest BEAM
category (35.7 at 1M, 32.5 at 10M)**, and its docs concede knowledge-update is the hardest
LongMemEval category "for an additive, ADD-only architecture". A published memory number
is a lead, never evidence. No arm was built in this run (see Leads).

The source partly answers one open lane question: **the detail-against-currency middle.**
Its answer mirrors the one the lane imagined. Nothing is rewritten, and currency becomes a
*ranking* signal from temporal metadata written at extraction. That answer depends
entirely on the write-time dates being right, which is where the run found the defect.

## Design record (Phase 2d)

**D1 - ADD-only extraction; supersedence moves to read time.**
- decision: inference emits only ADD with `linked_memory_ids`; UPDATE/DELETE were removed
  from the write path in 2.0.0.
- forces: a write-time rewrite is irreversible, made against a 10-candidate neighbourhood,
  after the agent has already replied; two model calls became one.
- buys: no information loss from premature consolidation; the old and new belief both keep
  their dates.
- rejects: the tree's own previous two-call ADD/UPDATE/DELETE pipeline.
- where: `docs/changelog/sdk.mdx:348 "Replaced 2-LLM-call pipeline with additive extraction"`
- stage: write, the decide-what-changes step.
- corpus: **agent-memory/consolidation** § Supersedence models it ("supersede, don't
  replace"; states close, events accumulate). Catch, with a published cost.

**D2 - Two clocks, and only the observation clock may ground a relative reference.**
- decision: the extraction prompt takes an Observation Date and a Current Date as separate
  inputs and forbids the current date for grounding.
- forces: extraction is asynchronous and may be a backfill; a store read for years cannot
  re-ground a phrase it already resolved.
- buys: memories that stay true as they age.
- rejects: a single "today" (the previous prompt's `datetime.now()`, formatted once at import).
- where: `mem0/configs/prompts.py:526 "This is your ONLY temporal anchor for resolving time"`,
  `mem0/configs/prompts.py:1012 "observation_date = current_date"`,
  `mem0/memory/main.py:818 "raise ValueError(get_temporal_feature_error_message("`
- stage: the distillation step, the one moment the relative phrase is resolved.
- corpus: **NONE.** Nearest: `agent-memory/consolidation` ("dated where time matters") names
  the date, not the clock it was grounded against; `agent-memory.md` § Provenance lists
  "when it was distilled", which is the writer's clock. Cross-bundle neighbour
  `llm-observability/.../dual-clock-event-time` routes *reads* between two recorded clocks,
  and a distillation leaves no second clock to switch to. HOME IF NEW: agent-memory.

**D3 - Generous extraction; dedup is downstream.**
- where: `mem0/configs/prompts.py` "When in doubt, extract."
- corpus: **agent-memory/episodic-capture** § "Capture is generous; judgment is deferred". Catch.

**D4 - The external graph store is replaceable: ~4,000 lines of five graph drivers deleted,
graph memory reduced to in-store entity linking.**
- where: `docs/changelog/sdk.mdx:368 "External Graph Store Removed (OSS)"`
- corpus: **agent-memory.md** § hierarchy ("expect recall quality to come from the
  transitions, not the topology"). Catch, and an independent third sighting of that hedge:
  a vendor removed the graph from its own open build.

**D5 - The temporal signal is additive and never filters.**
- decision: temporal scoring nudges rank and "never drops" a semantically strong match.
- forces: a filter that misclassifies temporal intent loses the right memory outright.
- buys: recall safety.
- rejects: temporal filtering.
- where: `docs/core-concepts/memory-evaluation.mdx:54 "relevant memories are never dropped"`
- corpus: **not settled** (partial). A boost that can be outranked by semantics cannot, by
  construction, retire a contradicted belief, and that may be the mechanism behind 35.7.
  `recall-injection` was not read. Untriaged.

**D6 - An open library refuses hosted-tier parameters and fetches a remote notice config
with a variant split.**
- where: `mem0/memory/notices.py` (`_REMOTE_CONFIG_URL`, `variant_split`)
- corpus: `operations/.../plan-entitlements` (deployment-mode short-circuit) is the nearest
  neighbour. Partial; untriaged.

**Routing count.** Per system, NONE: write path 1 (D2), read path 0 settled (D5 unsettled),
boundary 0, evaluation 0. Whole tree: 1 settled, 2 at most. No shared HOME IF NEW at three.
**No forge handoff.** A library, as expected.

## Applied (Phase 7.5)

**rebase-the-varied-input / personas / code / better / ab-paired.** The seam was chosen
**to falsify**: the memory-year harness already injects a clock and ships a purity check
for this exact defect. It could not see the defect. A full-history copy that stamps the
wall clock onto every recalled line **passed 46/46 probes** under the shipped check,
because the check masked every date before comparing. B rebases dates onto each replay's
base. Target: caught 0 -> 46/46. Floor: full-history, none, raw-retrieval and
hybrid-verbatim PASS 0/46 under both arms. The four model-bound arms were not re-checked.
**Second finding at the same seam:** the id pattern held four literal 0x08 bytes where
`\b` was intended, so id erasure had never matched anything since the commit that added it.

**observation-clock / personas / simulation / unmeasurable.** The consolidation prompt
prints each episode's instant but never states now or asks for grounding, and its own rule
5 uses "today". The ladder cannot measure it: **12 of 3,571** replayed events carry a
relative reference, all one template ("X is Y from today, not Z"), consolidated the same
simulated night. Every arm ties on this axis by construction. Instrument named in the row.

**observation-clock / source tree / simulation / unmeasurable.** Structural: the rule is
stated three times in the live prompt and unsatisfiable on every path the open build
exposes. Instrument: a stub model recording the rendered prompt.
