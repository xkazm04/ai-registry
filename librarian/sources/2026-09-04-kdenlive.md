## The design record

### System A — the reversible model layer

**A1. The forward operation emits its own inverse.** `corpus: NONE`
- decision: every mutating model operation takes `Fun &undo, Fun &redo` and appends a
  closure capturing the value it just overwrote; `PUSH_LAMBDA` / `PUSH_FRONT_LAMBDA`
  compose them with short-circuit on failure.
- forces: 294 operations, deeply nested, several destroying information; a hand-written
  inverse per operation would be 294 second implementations.
- buys: no drift surface, free reversal of fan-out and of information-destroying steps,
  and the accumulated closure doubles as the rollback path for a compound operation
  that fails partway (38 sites).
- rejects: command-inverse (the dual-maintenance tax) and snapshot (document-scale
  memory). Also rejects, silently, any persistable history.
- where: `src/undohelper.hpp`; `src/timeline2/model/timelinemodel.cpp` (`local_undo()`)
- stage: the mutation itself, not the stack
- corpus: NONE. `undo-history` opens "There are two ways to make an action reversible"
  and prices exactly two. The enumeration was incomplete.

**A2. A whole-model invariant checker, asserted after every transition.** `corpus:`
`test-input-generation/inside-out-invariants` — models it, including the "expose a
checking entry point, not the state" step. **Catch.** 775 assertions and a 194-line
checker recorded as an application instead.

**A3. Test access through one named friend facade.** `corpus:`
`guest-language-introspection/flag-gated-debug-global` — models the rule (one named
door, default closed). Kdenlive's is a compile-time `friend class KdenliveTests` in 15
classes, with `// #define private public` left commented at `tests/test_utils.hpp:25`
as the recorded migration away from the blunt instrument. **Catch**; the migration is
application-grade evidence, not a new technique.

### System B — the defect-capture loop

**B1. One reflection vocabulary serves the fuzzer, the logger and the reproducer.**
`corpus: NONE`
- decision: model classes and their mutating methods are registered in RTTR; the fuzzer
  composes from that table, the logger records top-level calls against it (92 `TRACE`
  sites, depth-suppressed), and `print_trace` renders the sequence as compilable C++.
- forces: a stateful GUI model whose defects are compositional and whose users produce
  sequences no generator author writes.
- buys: a user's crash and a fuzzer find minimize into the same artifact and enter the
  same regression lane; a vocabulary change breaks stored cases at *compile* time.
- rejects: seed-backed regressions, and UI-level action logs (unreplayable).
- where: `src/logger.hpp`, `src/logger.cpp:150`, `fuzzer/fuzzing.cpp`,
  `fuzzer/main_reproducer.cpp`, `tests/regressions.cpp`
- stage: the input-supply lane
- corpus: NONE. `seed-is-not-a-reproduction` closes with "**Three lanes**, and they are
  not interchangeable" — fresh randomness, persisted corpus, hand-written. All three are
  *authored*. The field is a fourth source and the enumeration did not contain it.

**B2. The persisted regression artifact is generated source code.** Folded into B1
rather than landed separately — it is the serialization half of the same decision, and
`seed-is-not-a-reproduction` already owns "persist the derived input". The C++-source
form is written up inside B1's technique as the strongest realization of that rule.

### System C — the project document format (handed off)

**C1. The saved document is a valid input to the rendering engine.** `corpus: NONE`
- forces: gen-1 needed the engine to understand the project; the alternative was an
  export step and a second format.
- buys: the engine renders project files directly; the application opens the engine's
  own render files as ordinary media; library assets *are* render files.
- where: `dev-docs/fileformat.md`

**C2. A duplicated projection drifted; the fix was deletion, not synchronisation.**
`corpus: NONE`
- forces: gen-1 duplicated project data into the outer engine-facing structure. Recorded
  failure, in the tree's own words: "the effects as rendered got out of sync with the
  effect parameters as set in the Kdenlive user interface."
- buys: one writer. Recorded as "much more stable project behavior", plus the files
  became hand-editable.
- where: `dev-docs/fileformat.md`, Generation 2

**C3. Machine-facing serialization is locale-independent; the user's locale lives only
at the presentation boundary.** `corpus: NONE` for the serialization half
- forces: a *process-global* setting (`setlocale`) required by the engine; where the
  user's locale used a comma, engine properties were converted on save and "the project
  file ends up corrupted", "causing many crashes".
- buys: files that mean the same thing in every region.
- rejects: careful coding at each call site — the global is set by a dependency, so the
  property is achieved by pinning it and testing under a hostile locale.
- cost paid: a deliberately backwards-incompatible format generation (gen-4).
- where: `dev-docs/coding.md` § Locale handling; `dev-docs/fileformat.md` Generation 4
- corpus: `i18n/locale-runtime` is entirely presentation-side (first paint, switching,
  mirroring). Boundary now stated from both sides.

**C4. Five numbered format generations, each naming the versions that produce it.**
`corpus: partial` — `migrations` is database schema, `versioning-snapshots` is durable
version history. Landed inside the new subject as `format-generations-are-declared`.

**C5 (found during the sweep, not in the original count). Gen-2 used a private
namespace and never declared it**, so files were accepted by the engine and *invalid to
standard tooling* for years; the docs carry it as a known gotcha, not a fixed bug.
Landed as `ignorable-extensions-must-be-declared`.

### System D — reference-integrity repair

**D1.** `documentchecker` (2,063 lines) classifies broken external references as a
10-type × 7-status matrix and offers repair at load. `corpus:`
`game-production/regeneration-vs-repair-economics/defect-class-to-remedy-map` models it
and models it **better** — remedy→class direction, and admission only on a measured
cure. **Catch**, cross-bundle; recorded so a later run does not re-derive it.

## Applied (Phase 7.5)

**`execution-emitted-inverse` → goat, mode `code`, verdict `better`, proof `ab-paired`.**
Seam: `src/lib/dnd/operations/grid-plans.ts`, `createUndoableOperation`'s rollback,
which reversed a displacing assign by removing the placed item and then gave up — *"we
can't restore it without more info (the displaced item's full data would be needed)"*.
The apply step refuted that comment: `buildAssignPlan` already captures the displaced
item into `resultMeta.metadata.displacedItem` at the instant it is still on the grid.
The reversal was written in a different function from the mutation, which is exactly the
failure the technique names. Measurable: pre-operation state fields restored by undo.
**A=1/4, B=4/4** on the real modules with an identical fresh store. Shipped (`f3c9594`).

**`field-captured-operation-traces` → personas, mode `experiment`, verdict
`not-better`, proof `ab-paired`.** Seam: `src-tauri/tests/render_plan_proptest.rs`
against `engine/render_plan/compile.rs`. `compile()` rejects only `fps == 0` and snaps
every boundary to `1/fps`; `arb_fps()` drew from `{24, 30, 60}` — three friendly
divisors. Widened to a 4:1 mix with `1..=240` and ran 2,000 cases per property:
**0 failures** (arm A's space is a strict subset of arm B's, so 0 vs 0 over 8,000
cases). The bound was real; closing it revealed no defect, so **no field lane is earned
here yet**. The widened generator was kept and shipped (`25233f43d`) because it is free
and correct on its own terms.

## Seam search, so the absence is evidenced and not assumed

For `field-captured-operation-traces` the technique needs a randomized generator with a
vocabulary to share. All eleven fleet trees were checked at the manifest level for a
property-testing dependency (instrument asserted against a known positive first):
**one hit** — personas. Ten trees have no generator, so they have no seam for this
technique, and that is a searched absence rather than an unattempted row.

## Leads

- **The tree implements the fourth-lane mechanism completely and does not run the
  lane.** The `TRACE` macros and the crash-time `print_trace` live in the fuzzer and
  reproducer; the shipped application installs no signal handler and emits no trace when
  a user's session dies. Return condition: when a project in the fleet has both a
  generator vocabulary *and* a persisted corpus of real user documents, measure whether
  field-sourced inputs reach compile paths the generator cannot.
- **`Q_ASSERT` on rollback is compiled out in release.** The short-circuit contract that
  makes the emitted-inverse model safe is checked in development and hoped for in
  production. Return condition: when a project adopts the emitted-inverse model and
  needs a production-safe failure mode for a rollback that itself fails.
