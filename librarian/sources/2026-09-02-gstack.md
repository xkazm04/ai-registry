### Technique `host-contract-compilation` (agent-instruction-files)

From D1. `single-source-topology` covered hosts that differ in file name; this covers
hosts that differ in accepted fields, tool vocabulary and capability: a declarative
contract per host, suppression by capability validated against a section registry,
goldens and prose validation per render into a temp dir, the cross-model boundary
instruction as a host-pair property, and the instruction-only tier for hosts with no
install arm. Boundary to `agent-cli-transport`.
