## Experiments and apply

- **Floor, source:** the built binary on a five-test suite with one failure - plain 73 B, injected structured 3,024 B, emitted 224 B, booked 95.1% saved; the guard silent. On a lint run - default 3,349 B, concise 1,133 B, injected 13,782 B, emitted 1,313 B, booked 90.5%.
- **Estimator, source:** 84 paired filter tests through the length estimate and two subword tokenizers - mean saving 50.6% against 51.2%, per pair -29.7 to +16.6 points, 1.17 tokens per estimated token.
- **Decode, fleet:** on this machine (OEM 852, ANSI 1250) from a console-less parent the console lookup returned 0 and the shell wrote OEM; lossy UTF-8 lost 4 of 9 letters, whole-buffer OEM mangled a mixed stream's UTF-8 half, per-line was exact. The source's console-less fallback (the ANSI page) decoded the same bytes without error into four wrong letters.
- **Applied:** decode-child-output-per-line in personas, `code`, better, ab-paired, `5ab86317e9`; untransformed-arm-is-the-floor in personas (KPI parser recording 0, 1 and 2 from programs that never started), `code`, better, ab-paired, `3de69f5027`; ledger rows `fc088e19db`. Both seams chosen to falsify: the whole-buffer decode and the exit-code check both failed as predicted. the-baseline-is-the-untouched-path: experiment on the source, not-better for the source's booking; fleet unapplied. rewriting-under-a-foreign-gate: unapplied, no fleet project rewrites an agent's commands under a host's rules.
