# The bundle says "factual", and the test used a library built to have no scene in it

**Operator, 2026-09-20**, on the nine-scenario envelope: *"majority of them are not
realistically usable to compose any scene from movie, game or any type of media
content... Either we extracted the knowledge incorrectly and we know nothing about
scenemaking, or we do have some knowledge and don't use it for the intake tests."*

The either/or has a third answer, and all three parts are separately true.

## 1. The knowledge is good, and it is not the knowledge the complaint is about

`media-generation/index.md`, first sentence: **"The craft of producing FACTUAL
audiovisual content with generative models."** Every `narrative-craft` subject's
`use_when` confirms the scope in its own words - `short-form-narrative-structure`
says *"writing or reviewing a factual video script... a correct explainer"*,
`narrative-engine-selection` says *"starting a factual video script"*,
`trailer-structure` says *"a promotional cut for a longer work"*.

So the bundle never claimed dramatic fiction. What it does claim it does well:
`cinematic-language` (7t) is genuine fiction-film craft imported as a *visual
register* layer, `character-identity-continuity` knows the hard thing (*"style
survives on words and identity does not... a face cannot be named"*),
`visual-style-locking` and `scene-grammar-progression` cover style persistence and
coverage/axis/eyeline.

## 2. A real hole, and it is the one the operator is feeling

Across 471 subjects there is **no subject for dramatic scene construction** - a
situation with a want, an obstacle, a turn, subtext, and the coverage that renders
it. `game-production` holds only `branching-narrative-graph-validation`, which
validates a graph rather than writing a scene. `cinematic-language` says how a shot
should *mean*; nothing says what the scene is *about*.

This is a scope hole, not an extraction defect. The bundle was forged against a
factual-video studio and is honest about it in line one.

## 3. The test used almost none of what we DO have

The envelope probe rendered nine isolated stills. Against the corpus's own
prescriptions:

| corpus says | the probe did |
| --- | --- |
| `approved-reference-sheet` + `style-block-restated-every-call` | hand-wrote one style sentence |
| `reference-admitted-late`, `reference-shows-only-invariants` - and *identity cannot be carried by words* | **no image reference at all**, pure text-to-image |
| `scene-grammar-progression` - master -> mediums -> OTS -> singles -> inserts, axis and eyeline held across clips | one isolated single per scenario; axis and eyeline are undefined with one shot |
| `genre-visual-contracts` - *"Genre is chosen first, because it constrains everything below it"* | no genre contract |
| `one-function-per-visual`, `visual-function-vocabulary` | declared a composition, never a function |
| `identity-split-from-state` | no identity to split |
| `but-therefore-beat-linking` | no beats to link |

## 4. The category error that guaranteed the result

The nine "scenarios" were the consuming project's `SUBJECT_RECIPE` - a **trailer
plate** library, whose own header says it is *"SHAPE FIRST, NOUNS SECOND"*, that
**"the beat's own words never reach a model through this path"**, and that the
recipes *"avoid faces, hands and two-figure contact wherever the recipe allows"* for
generation-risk reasons.

A trailer plate is engineered to be a striking fragment with the scene removed -
`trailer-structure` owns `withholding-budget` and `concealment-and-its-tells`
precisely because withholding is the form's job. **The run used the one artifact in
the fleet explicitly designed to contain no scene as its test of scene-making**, then
graded it for scene-ness. The stock-photo result was determined at selection time.

## Leads

- **A dramatic-scene subject is unowned.** Return condition: a connected project
  needs fiction rather than factual output, OR a second independent source converges
  on scene construction as a craft we keep reaching for. Note the honest prior: the
  fleet's video studio makes factual films, so this may stay correctly unowned. Do
  not forge it on one complaint.
- **A scene-level scenario set does not exist.** The envelope proves *composition*
  only. A scenario that could test scene-making needs a persistent character carried
  by a reference, a persistent place, a declared genre contract, a dramatic beat, and
  at least three shots in a coverage progression - none of which the current nine
  have. Return condition: before the next render proof in this bundle.
