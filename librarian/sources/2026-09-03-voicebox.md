### `voice-io` +3 techniques, +3 applications

A grep of the entire subject for `unattended|programmatic|agent-initiated|machine caller|impersonat` returned **zero hits**. Every consent, arbiter and
mute rule in a 13-technique subject assumed speech is requested by the user or
by a surface *inside* the product. The source ships a machine-facing surface on
which an unattended client makes the machine speak in a clone of a real
person's voice, which inverts consent (the user is not the requester), identity
(the requester must be named) and acceptance (nobody is listening to catch a
bad render).

- `unattended-caller-attribution` — the producer raises the attribution
  surface; it is not the caller's job to disclose itself.
- `caller-scoped-voice-binding` — precedence ending in **error**, never silent
  fallback; a self-asserted id is disambiguation, not authentication.
- `render-acceptance` — `failure-not-empty-success` **inverted**: success that
  is actually failure. Renamed from `synthesis-output-verification` on the
  worker's argument that "verification" reads as quality scoring, which the
  technique explicitly says it is not.

Applications add **`python`, a stack `voice-io` had never carried** (its ten
applications were node/react/rust).

### Three techniques and one amendment elsewhere

- `sidecar-provisioning/change-rate-partitioning` — cut a payload where its
  parts change at different rates. The verification pass found the boundary
  that makes this a technique rather than a duplicate: `release-pipeline/version-single-truth`
  holds that a version is **one fact with many replicas**, and this asserts
  **two facts**, which is `one-authority-per-vocabulary` honoured, not broken.
  It ships with a mechanical test — *if bumping one should force the other,
  they were replicas and you have a drift bug.*
- `packaging/adoption-time-packaging-audit` — every existing packaging
  mechanism is post-hoc; this is the subject's own force ("The build output is
  not the product. The installed tree is.") moved left of adoption.
- `dependency-declaration/unsatisfiable-set-empirical-gate` — and its golden
  path claimed "the scalability invariant has **exactly two answers**", which
  this falsifies. Corrected under the `content` lock, because a live sibling
  held that subject.
- `packaging/signing-and-trust` **amended**: the file's enumerated partial
  failures are all outer-signed / inner-missed; this is the inverse — payload
  attested, wrapper not, toolchain reports success. The file's rule survives,
  which is what makes it an amendment and not a competing technique.

## Catches — the corpus already said it, and said it better

1. **The clipboard ownership token.** `transcript-handoff-receipts` rule 2
   already says "restore only while the product still owns the channel… if the
   clipboard's sequence counter moved". The source implements exactly that —
   and **none of rules 1, 3, 4**. It restores on a fixed 400 ms timer, which
   the technique names "a race by construction". Landed as a **negative
   source-tree application**: the ownership check protects a third party's
   newer write and does nothing about the target reading after the product's
   own restore. Best evidence the run produced.
2. **The unauthenticated local listener.** `mcp-tools/transport-selection:95-99`
   already says "A local HTTP listener is not 'local' in the trust sense". The
   source ships one and documents it as a stated non-guarantee, with a live
   DNS-rebinding report against it. Not written up: **`mcp-tools` is held by a
   live sibling run**, so the application was left to them.
3. Engine registry + adapters + capability probing + retired-engine
   normalization → `voice-io/engine-abstraction`, in full.
4. Three-flavour voice identity (cloned / preset / designed) →
   `authored-voice-identity`, which already owns the three specification kinds
   and the consent line.
5. Accelerator sizing and variant selection → `sidecar-provisioning/grade-selection`.
6. One-model residency and VRAM-bounded concurrency → `backend-platform/work-execution/admission-queue`.
7. Non-destructive effect versions with a default pointer →
   `operations/governance-and-records/versioning-snapshots`.
8. Deterministic prefilter before the probabilistic stage → already owned in
   another bundle by `recruiting/cv-authenticity-screening/ground-the-model-against-a-deterministic-prepass`.
   Cross-bundle: the rule converges, the discriminator differs. Not linked.
9. Serialized exclusive-resource access → `admission-queue` + `concurrency-guards`.
10. Locale parity → `client-architecture/i18n` owns `completeness-gates` and
    `interpolation-and-plurals`; the law `localization#coverage-is-counted-not-claimed`
    already exists. The source is a **counter-example**, not a gap (below).
11. Atomic multi-file artifact arrival → `sidecar-provisioning/atomic-downloads`.

## Leads — real, unproven, with return conditions

1. **`coverage-does-not-nest`** (proposed law, returned by the packaging
   worker, not added). *A property verified on a contained artifact is not a
   property of its container.* An attested payload in an un-attested wrapper, a
   scanned image in an unscanned archive, a signed binary in an unsigned
   installer. Distinct from `gate-sees-target`, which is proxy-vs-target; this
   is about **scope** — the gate saw a real target, just not the one that
   ships. Four sightings claimed across `packaging`, `supply-chain`,
   `sidecar-provisioning`. **Return when** a second independent run sights it.
2. **`host-request-is-not-effect`** (proposed law, returned by the forge
   worker, not added). *When a process asks a host it does not control to
   perform an act, the call returning is not evidence the effect occurred.*
   Four sightings inside the new subject alone, plus `transcript-handoff-receipts`'s
   central claim (the paste chord is only enqueued). Distinct from
   `verdict-survives-boundary` — that is a verdict erased in transit, this is
   there being no verdict at all. **Return when** a second run sights it, or
   when the new subject's applications accumulate a third.
3. **The corpus has no home for "an instrument that is registered and inert".**
   U1 is the evidence; the law candidates above are adjacent but neither is it.
   **Return when** a second source produces the same shape.
4. **Locale parity as a measured counter-example.** The source has no i18n
   check in its build at all; measured against `en` (850 leaf keys), `es`/`it`/`ko`
   are complete and `fr`/`ja`/`pt-BR`/`zh-CN`/`zh-TW` are each missing **the
   same 18 keys** — one feature wave translated into three of eight locales —
   and `ja`/`zh-CN` carry mechanically mirrored `_one`/`_other` pairs with
   byte-identical strings despite having no plural category. This is a clean
   field instance of `localization#coverage-is-counted-not-claimed` and of
   `i18n/completeness-gates`, and it belongs in an application against the
   fleet peer that solved it (seven enforcement scripts and a CONTRACT.md).
   **Return when** the peer study lands and the comparison can be written from
   both trees at once.

## Method observations from this run

- **`run-board.mjs check` under-reports.** It returned `clear` for `mcp-tools`
  and for `dependency-declaration` while `run-board.mjs list` showed live
  siblings holding both. `list` was right twice. Trust `list`; `check` cost
  nothing here only because the list was read as well.
- **Two `[V]`-marked anchors from the front half did not exist.**
  `InputMonitoringGate.tsx:164-172` in a 108-line file; `input_monitoring.rs:43-68`
  in an 82-line file. The forge worker caught both by opening them. A `[V]`
  mark is a claim, and a downstream worker that opens the file is the only
  thing that checks it.
- **Both dispatched workers died mid-run on a session rate limit and were
  RESUMED, not re-dispatched.** Neither had written a byte; both finished with
  their reading context intact. The re-dispatch would have paid for the
  neighbour reading twice.
- **The regenerated index absorbed four sibling runs' uncommitted subjects**
  (`invariant-placement` ×17 and others), so `index.json`/`catalog.json` were
  left uncommitted and `taxonomy.json` was committed as a **crafted blob**
  carrying only this run's line — the sibling's entry would have put a
  reference to an untracked directory into `HEAD`.
