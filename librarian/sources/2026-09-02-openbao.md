## The five landings, and what the source got wrong

**1. Canonical once (scope-design).** Four security fixes in one year are
one shape: policy names lowercased at lookup but checked raw at assignment
(CVE-2025-5999, CVE-2025-64761); alias lookahead case-insensitive at login
but not at the lockout counter (CVE-2025-6004); the tenant path `root`
resolving to the parent (GHSA-mwr2); a one-time code whose replay cache
keyed on the spaced form while the verifier stripped spaces
(CVE-2025-6014). The corpus said "exact equality on canonical forms" and
never said *where* the form is made. Applied to the registry's own run
board: the SAME SOURCE guard missed 3 of 4 spellings of one repository;
fixed and shipped.

**2. The half-success (failure-direction).** CVE-2026-46405: an auth
method returned an auth block *and* an error; the core minted a token. The
fix (`request_handling.go:1579`) is two lines and shipped beside a semgrep
rule for the shape. The enumeration in `failure-direction` had six rows,
all failures resolving permissively; a success travelling with a failure
was the seventh. Applied to a dashboard's fetch hook: `not-better` -
display values beside an error are legitimate when the surface renders
the error first, and that condition is now in the row.

**3. The mirror's derived state (topology-declaration).** Twelve fragments
over a year, one per derived cache on read-serving standbys (leases, salt,
MFA, quotas, policies, mounts, namespaces), ending in "restart the standby
on an unknown system key" (PR 3555, `invalidation.go:465`). The corpus had
no standby material at all (one grep hit in 3,790 files), and the one-way
mirror's promise was stated for records only. Applied to a desktop app's
per-process connector cache: `better` on the revocation case.

**4. Renewal must not queue behind the work (lease-renewal).** PR 3913:
transaction limit set one below the connection limit so the HA lock's
renewal always has a slot. **The source's remedy inverted on a
single-writer engine** - measured with a fleet project's own parameters, a
dedicated renewal connection *failed* where the shared writer succeeded,
because its busy-timeout turned a wait into an error. The amendment
carries both halves and the tell (can two connections hold write
transactions at once). This is the "a source that implements a good idea
in one engine hands you the boundary" case, and the not-better row is the
run's most useful.

**5. Terms for uninvited agents (workspace-ancestry-isolation).** The
source's `AGENTS.md` is the first instruction file this skill has met that
is addressed to agents the author did not run: it refuses generated
contributions, permits analysis, gives four rules for machine-assisted
security reports, and hides a disclosure canary in a comment. The corpus
owned the reader's chair and not the author's. The discriminator with
prompt injection - who owns the tree - is stated on the author's side.
Applied to the registry: `not-better`, precondition absent (one owner, no
outside contributions), and that condition is the amendment's last
paragraph.

## Leads

- **15. Count-based compaction resets with the process.** PR 3381: the
  log grew without bound when fewer than `snapshot_threshold` entries were
  written before each restart. No home. *Return when* a second source
  states it, or a fleet tree grows a log-structured store with a
  count-based compaction trigger.
- **19. A threat model that enumerates its out-of-scope.** The source's
  list includes storage-backend control, memory analysis, malicious
  plugins, administrator-supplied configuration, and *fingerprinting*
  (traffic shape, version strings, tenant existence via unauthenticated
  paths). The security bundle has no threat-model subject. *Return when*
  the bundle grows one or a fleet project writes a threat model.
- **20. Unstable native dependencies as auto-restarting external plugins.**
  The source moved every cloud-KMS and PKCS#11 seal out of the binary into
  plugins that "automatically restart and recover from crashes, avoiding a
  full instance restart when a seal reaches a bad state (e.g. via a
  misbehaving PKCS#11 library)". Likely home
  `optional-dependency-degradation`. *Return when* a second source
  process-isolates a native library for the same reason.
