# React 19.3

Intake 2.10.0, run 2026-09-15. A source originates a finding; it never authorizes one.
The web instrument returned 4,367 words: the post, its inline sandboxes and the
changelog. The whole text was read.

**Class.** The vendor's own post about its own release, so a **vendor release
announcement**. It leans toward the release-walkthrough sub-class more than most:
four sections say what was wrong before (string coercion at DOM sinks, pass-through
provider wrappers, entangled Transitions, animating cached UI). The class entry
predicts the yield sits in the code samples, and that the corpus is ahead on craft.
**Expected yield said before the table: currency, catches, and at most one boundary
amendment where the reference docs make a sample's missing constraint visible.**
Both predictions held. Three of the four craft rows were catches or weaker than the
corpus. The one landing came from what the samples leave out: none of the six
animation sandboxes handles reduced motion.

**Board.** No live siblings at claim or at any later check. One subject claimed at
Phase 7 (`software-engineering/ui-surfaces/feedback-and-style/motion`).

**Declared focus from the previous row** (bind a survey's currency row to a concrete
application before spending a fetch; no composite techniques from a product surface;
freshness metadata at its declared granularity). The first two applied and held. No
fetch went to currency: npm answered "is 19.3.0 published" at no cost, and eleven fleet
trees answered "who is on it" (all on 19.2.x). The third decided a landing. The
application's `verified_on` covers sections this run did not re-check, so the new
section is dated inline and the frontmatter date did not move.

**Fetches: 1 of 3.** `react.dev/reference/react/ViewTransition`, for reduced motion,
the activation classes and interruption. Everything else was corroborated by
experiment or by trees.

## Apply (Phase 7.5)

One row: `reduced-motion-mechanics` x personas-web, `experiment`, `better`. **Seam
chosen to falsify:** the tree's own reduced-motion block, copied verbatim, because a
real block might carry an `html`-level or inherited rule that a synthetic reset lacks.
A caught outcome would have shrunk the amendment to a note about hand-written resets.
The finding held. **Not shipped:** personas-web has no view transitions and pins
`react ^19.2.8`, so nothing in the tree could see the change. The row files the rule as
the adoption change and carries the return condition. Committed in personas-web
`cd5f97d` (applied row only, on its active branch, not pushed).

Structural fact from the seam hunt: seven fleet trees carry the same universal reset.
The only tree that hand-rolls transitions carries both a `matchMedia` call-site gate
and an explicit pseudo-element rule. React 19.3 forbids the gate on migration and
keeps the rule.

## Catches

- **Row 3.** `placeholder-design` (appearance delay on the placeholder; warm loads
  never flash) and `arrival-choreography` (warm load paints settled content with no
  cascade) state the post's three principles more strictly. The corpus's delay
  window is the better rule. The post's "fallbacks appear immediately" works only
  because the framework throttles reveals, which the post does not mention.
- **Row 6.** The React reduced-motion application already documents render-time
  preference reads diverging between server and client, and the wrapper that fixes
  it.
- **Row 9.** Group refs do not replace `always-present-anchor-wrappers`. A ref exists
  only after script runs, and those wrappers exist *for* the pre-script document. The
  discriminator is written here so a later run does not propose the swap.

  falsifier for any direction inferred from a before/after index.

## Leads

- **Row 7, injection-sink typing.** Across 1,696 software-engineering techniques the
  corpus has zero material on DOM injection sinks (no `innerHTML`, no sanitizer, no
  typed-sink policy), and no fleet tree enforces `require-trusted-types-for`. Strip
  survivor: *any layer between a sanitizer and a sink must pass typed values through
  untouched; coercing to a string discards the policy's proof*. Return condition: a
  fleet project renders untrusted HTML, or a security subject for browser output
  sinks is forged.
- **Row 10.** Return condition: a fleet Next tree upgrades to react >= 19.3; its
  pass-through providers become deletable.
- **Row 11.** Return condition: an application citing StrictMode double-mount is on a
  server-rendered stack that upgrades to 19.3.
- **Row 12.** Whether `Error.cause` and `AggregateError.errors` cross the Flight
  boundary in production builds, or only in development, decides whether
  `origin-non-disclosure` gains a boundary case (a wrapped upstream error's cause
  carrying origin detail). Return condition: one read of react PR #35810, spent by a
  run touching `stream-proxy-hop`.
- **Row 13.** 19.3.0 is on npm; eleven fleet trees pin 19.2.x. No application owns a
  React-version clock that this resets. Return condition: the first fleet upgrade.
