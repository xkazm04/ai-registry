# Archify — the acceptance of a document nobody wrote by hand

## Class and read fraction

A **practitioner build-walkthrough in repository form**, and an unusually good
one: the operating layer is thicker than the product. The landing page is 2,051
words. In-tree markdown is roughly 130,000 — 49 dated visual-evolution research
rounds (105,797 words alone), a benchmark with a written fair-run protocol and

measurements corroborates itself.

The demo half — the gallery, the design system's aesthetic argument, the
screenshot set — was read and produced nothing, exactly as the class predicts.
The segment a build-walkthrough is proudest of is where its boundary is
missing.

## The gap the operator asked about

**"Automated docs creation" did not exist in the corpus, and the reason it did
not is instructive.** Three subjects sit adjacent and each one's stated boundary
excludes it:

- `codebase-stewardship/docs-sync` (11t) owns the *coupling* between source and
  prose and the machinery that detects drift — it asks whether a document is
  still true.
- `build-and-release/codegen` (6t) owns *derived source*: deterministic
  generators, drift-gated by regeneration. Its spine is
  `derivation-names-recomputation`.
- `ui-surfaces/published-surfaces/docs-content-model` (5t) owns the record shape
  of a published topic.

The missing subject is the one whose generator is **non-deterministic**, which
is precisely the property that makes `codegen`'s whole discipline unavailable: a
regeneration diff over a model author is noise, so the acceptance burden moves
onto the artifact and the gates around it. That discriminator — determinism —
is now stated on both sides.

Landed as `engineering-process/codebase-stewardship/machine-authored-documentation`
(6th subject in a category capped at 10), golden path plus 7 techniques plus 1
application.

## Leads (with return conditions)

- **The export/viewer split as a general artifact property** — a generated
  artifact separating canonical bytes from reader exploration state, so that
  what is exported is what was authored. Return when a second independent source
  states the split, or when a managed project ships an artifact with a reader
  runtime.
- **Remote copy is never relayed into the conversation.** A self-updating
  package may render only locally-fixed text about an available update; the
  remote manifest's own summary is never quoted, summarised or translated. This
  is a prompt-injection boundary wearing a release-notes costume. Return when a
  second independent source shows the same rule, or when a managed project ships
  a self-updating skill.

## Cross-run convergence worth naming

`genesis-agi` ran in parallel today and landed a `three-state-outcomes`
amendment on `health-checks`, whose A/B found a tree that "already carries a

law across three domains* rather than proposed upward. The third sighting is the
one to watch: if a run lands this shape again where the law is **not** cited,
that is evidence the law's anchor text is too narrow, not that a new law is
owed.

## Apply (Phase 7.5)

One row, mode `experiment`, verdict `better`. Seam found in `politicas` — a
design-quality detector whose visual engine returns a finding or `null`, from
five places, four of which mean *not measured*. The caller collapses them with
`finding ? [finding] : []`.

The structural fact is stronger than the A/B and nobody designed it: the
detector's finding record has **no skipped type at all**, and no
skip/checked/denominator vocabulary exists anywhere in its CLI or entrypoint. So
the conflation is not a local oversight — the report has no vocabulary in which
a not-measured candidate could be expressed, which means every engine feeding it
must discard that information however carefully it was tracked upstream. A
denominator cannot be added at a call site; it has to exist in the record type
first.

Full write-up in the application document. No product code was changed: the
cross-repo lane was not confirmed, and `puppeteer` is absent so no live-page arm
was runnable. The seam is recorded in the project's `.ai/applied.jsonl`
(uncommitted).

## Method notes from this run

- **The line numbers in the application were wrong on first write** and were
  caught by opening the file — three of five citations off by 2–4 lines, because
  the guard text `if (!clip) return null;` appears twice in that module, in two
  different functions. Phase 8's "open one cited line" is not a formality; here
  it would have published four bad citations.
- **The A/B harness reproduced the defect it was testing.** Its first version
  mis-ordered the stubbed calls (the cleanup sits in a `finally` that runs
  *before* the compare), starving the compare of metrics. Arm A reported a
  uniform `null` across all six cases and could not show the harness its own
  bug; arm B's typed reasons did, on the first run. Recorded in the application
  because it is the technique demonstrating itself on its own instrument.
