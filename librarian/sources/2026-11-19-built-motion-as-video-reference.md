## Where practitioners disagree

- **Placeholder treatment (S1/D2), two channels against the corpus.** The corpus says "ignore the
  placeholder's content entirely", for a camera-angle still. S and D name every placeholder; D adds
  "marks the pursuing chameleon's position only ... do not copy the block's rigid motion". The
  discriminator: **does the placeholder stand where a real object must appear?** If yes, name it and
  keep only its place and path; if it only fixes the angle, disown it. Where the primitive's own shape
  performs the action (a figure opening a door), the action is kept.
- **Camera words over a plate, four positions.** Write start, move and end (11-16 Z, and D); write none
  (11-08 Mira pack, which breaks its own rule); compute per-shot framing and write no motion (S); add
  carriage in words (D). The discriminator: **does anything other than the prose control the camera?**
  A typed control does; a hosted reference video only conditions. Every channel that writes the move is
  on a hosted reference. Our depth route is a typed control, so silence governs it, and R13's s5102
  broke it ("a slow push in").
- **Text on a frame sheet (S6).** S prints camera action and seconds on each frame; the corpus allows
  panel numbers only. D casts no vote: his storyboard goes to the blocking agent. Unmeasured both ways.
- **3D as default (A2).** 11-16 Futurepedia: describe a 3D world rather than paint a flat canvas. A uses
  four methods and picks by look. The discriminator: **the medium follows the look's own production
  idiom**, and only realism-dependent elements (bodies, faces, complex action) leave code (A7).
- **Depth against grey (S2).** S chose depth on a host offering both; D sends shaded because his host
  takes video only. Not a contest.
