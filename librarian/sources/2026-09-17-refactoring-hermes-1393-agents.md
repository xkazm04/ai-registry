## Applied (Phase 7.5) and shipped (Phase 8)

**Row 1, personas, `experiment`, `not-better`, seam chosen to falsify.** Target: of
the 218 unused exports the tree's instrument reports under its wire-facing layer,
how many have a caller outside the TypeScript universe. A by-name grep across the
Rust tree returned one; the real join (the Rust side dispatches by string into a JS
method table resolved by reflection) showed that method table installs its own
implementation of the same name, so the export is a duplicate with zero callers and
the instrument was right. 0 of 218; floor held (the report unchanged at 317 files /
1,152 exports / 662 types). The class has no members in a private app with no
published surface, as its precondition says. **What the seam returned that the
landing did not say:** the Rust -> JS direction of the bridge had no join
instrument (the existing one covers TS -> Rust only). **Shipped**: personas
`2ad1cedc8` on its default branch - `scripts/build/bridge-methods-join.mjs` (33
dispatched, 153 installed, 0 unresolved; `--self-test` injects one uninstalled
dispatch and requires it reported alone), an npm script, a pre-push job, and the
applied row. Four files, pathspec commit, sibling WIP untouched, not pushed. Three
currency facts recorded in the project's ledger: the unused-export instrument left
CI on 2026-08-30 and is wired nowhere, red at HEAD with 317 files; dropping the
harness ignore changes files 317 -> 326 and exports not at all; one two-file dead
island confirmed by hand.

**Row 2, the fleet's worktrees, `experiment`, `unmeasurable`.** 52 worktrees across
three checkouts, five sessions live; the process table holds one editor extension
host and zero per-worktree language servers or watch-mode checkers. CLI agent
sessions spawn no per-checkout daemon; their resident cost is per session (58
runtime processes, ~24.7 GB, across five sessions), which no worktree-layer sharing
reduces. Instrument named: a worker profile that runs an LSP-backed check per
worktree and keeps the server warm. The technique's shape is already realized here
as the shared-install junction with "the worker's tests run" as the liveness probe.

## Corrections this run made to its own reads

- **A by-name grep across a wire boundary returns coincidences.** The one "live"
  hit was a duplicate implementation; the instrument had it right. The join has to
  be against the dispatcher's method table, not the string. Recorded as a lesson.
- **The harness ignore was not the mechanism.** The hypothesis that an ignore
  pattern hid the consumer was tested by dropping it (arm B) and refuted; the
  finding moved to the roster column rather than to a config fix.
