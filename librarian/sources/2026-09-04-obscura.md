engine, its own document tree, its own cascade/layout/paint pipeline, a devtools-protocol
server, an automation-protocol server, and a fingerprint-consistent transport. Mined

## The finding: a denial that went too broad

`backend-platform/language-runtime/guest-execution-bounding` was forged 2026-09-03. Its
"What the naive reading gets wrong" section opens: *"The first naive reading is a
watchdog: run the guest on a thread, kill it on a timer. It fails three ways."* Its
neighbour `capability-subtraction-sandbox` puts wall time on the **uncounted** list.
Together they say: wall time is uncountable, therefore uncapped, publish it and move on.

That position holds only where the host **owns the dispatch loop** and can insert a
counter. This source embeds a third-party script engine and can insert nothing — the
counted set is empty by construction — and it answers all three objections rather than
falling to them:

- *Cannot kill the thread without corrupting host data* — nothing is killed; a
  thread-safe termination handle the engine publishes makes the engine unwind itself at
  its own safe point, which is the same unwind a counted breach produces.
- *A timer is not deterministic* — conceded and reframed: this is a **liveness** ceiling,
  not a correctness limit, and determinism is bought back by nesting the bounds.
- *A single-threaded host has no thread* — guest execution is single-threaded and the
  watchdog thread still exists, because it touches nothing but the handle.

The corpus owned "how an interpreter you own governs itself" and had explicitly called
the other half naive. That is the best case the method describes: a source that located
something true where the corpus had drawn its denial too wide.

## Leads

- **Row 10 — port the bidirectional-edge-distance metric into `scripts/`.** Real, and
  deliberately not landed: the principle (a lossy projection scores two different
  layouts identically, so a comparison metric must preserve every coordinate it claims
  to compare) has no consumer in a text registry today, and porting image-comparison
  code nobody calls is ceremony. **Return condition:** when any registry instrument
  starts ranking on a projected score rather than on the thing itself — the closest
  candidate today is `research-map`'s slug-token overlap, which already scores two
  semantically unrelated documents identically and is the reason this method warns about
  near-empty results.

## Falsifiers run in-run rather than banked

The declared focus for round 12 was to stop writing falsifiers as return conditions.
Three were run and **two came back against the run's own hypothesis**:

1. *Hypothesis:* the fleet leaks detached children wholesale under async timeouts.
   **Refuted on the hot paths** — the target project had already found the mechanism
   independently and documented it in this source's own terms. That refutation is the
   corroboration; see below.
2. *Hypothesis:* two files that a file-level scan showed as unguarded were leaking.
   **Refuted** — both kill the child explicitly. Reported as catches, not as findings.
3. *Hypothesis:* the compile failure in the target project was caused by this run's edit.
   **Refuted by stashing the seven changed files and reproducing the identical failure.**
   Attribution by experiment rather than by assertion.

## Independent convergence, reported as convergence

Round 11 asked the next run to stop reporting an independent second sighting through a
column that says `not-better`. This run has the instance.

The mined engine wired external termination to stop a runaway page from wedging a
worker. The target project wired the same mechanism to stop a timed-out subprocess from
continuing to bill a user's account, and its source comment states the semantics in the
same words: without the guard the runtime **detaches** the child rather than stopping it.
Two systems, unrelated symptoms, same mechanism, neither aware of the other.

That is a second independent sighting of a rule — the strongest corroboration available
without a fetch — and the apply row says so in its note rather than recording the
project as having failed to improve. **The vocabulary gap is real and is now a lesson:**
`better` / `not-better` / `unmeasurable` has no cell for "the tree already does this,
independently", and this run recorded it as `better` only because 8 residual sites did
change. Had the coverage been complete, the correct verdict would have been unsayable.
