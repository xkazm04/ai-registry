## Banked wording, for a later run

**E1, `canvas-graph`.** An immediate-mode surface cannot be asked what it shows, and the test environment has no raster. Four oracles each see something real: render count per interaction, bitmaps minted through an injected factory, recorded calls with transforms, and non-events asserted by identity. None sees the picture, so a surface whose appearance is the product still owes one lane that rasterises. A fake context that accepts every call and records nothing is not a fifth oracle.

**E4, `sync-replication`.** A merge function is pure, so it has a proof that needs no network. Run each case three ways: local with remote, remote with local, remote with the first result. Compare the winning version and content and not only identifiers, because order witnesses the winner only where the copies' keys differ. Give the tie-break a case with different content at the same version, and test each input the function takes. Sabotage it and write down which test must go red.

**D1, in F.** Tenant isolation does not help when every record is in the right tenant. The principal is the person on the other end. Enforce it at the dispatch layer, which alone knows an agent is acting in a conversation, set the party from the job and never from an argument, and declare ownership per identifier field as data, with a write absent from the table refused. A fields-scoped-to-no-one entry deserves the same review as a new tool, and a scope awaiting later configuration is open until set.

**D3, in F.** A person takes an agent's sentence as a fact. Separate did the effect happen (publish the dispatch layer's own outcome, per run), does the text claim it (a narrow detector with negative controls), and may it go (only the gate decides). Keep produced, failed and uncertain apart.

**D4.** Row-level proofs measure a restricted role, and a service client bypasses it, so a cross-tenant defect leaves them green. Scan who obtains the client and which table it reaches, from source. A filter on the primary key alone passes the weaker rules, and a client reached through a parameter across files can be invisible to a per-file scan.

**D5.** An end-to-end pass through an agent includes the model's ability to work around what is beneath it. Collect the case through the agent and the tool called directly on the same raw text, as one unit, and treat a disagreement as the defect standing. An instruction in the description to pass raw text does not remove this. It does not replace the end-to-end run.

**X1, design only.** A page returns no status, so on a surface you own or are permitted to drive, a write is unknown until new evidence, bound to this action and absent from a baseline taken before it, says otherwise. A click, a confirmation already showing, matching text or a vanished element is not that evidence. Unknown is never failure and never retried. Prefer a published interface wherever one exists. Whether a surface may be driven at all is a question this rule does not answer, and it comes first.
