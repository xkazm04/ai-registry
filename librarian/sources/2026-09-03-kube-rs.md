## Design record (Phase 2d) - summary

Twelve entries in five systems (companion `2026-09-03-kube-rs.design-read.md`). System A,
the controller runtime: the reconciler is told THAT not WHY (A1); one slot per key with
earliest-wins, in-flight parking, debounce and a global cap (A2); deletion blocked by a
marker until dependents confirm (A3); ownership edges re-enqueue the parent (A4). System B,

adapter (C2). System D: per-field write ownership (D1). System E: a synchronous gate before
persistence (E1), lossless version conversion (E2). Counts before the decision: NONE per
system 2/1/0/1/2, no system at three; HOME-IF-NEW four on A3+A4+D1+E1, reached twice
