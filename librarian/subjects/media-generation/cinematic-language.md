## 2026-08-26 - /intake run 23 ([[2026-08-26-joyai-echo]])

- Amendment to `movement-motivation`: **when the camera is an input, the prose stops describing it.** The technique assumed prose is the only place the camera is decided; generators that take a camera path or action script as a typed input invert every rule in it.
- The discriminator is one question - *does anything other than the prose set the camera?* - and it is worth more than the amendment. The failure it prevents is a misdiagnosis: two authorities over one channel produce a compromise move matching neither, which looks exactly like the aimless drift of an undirected model and gets treated with *more* camera language, making it worse.
- The amendment draws where the silence stops, because drawing it too wide costs real control. Prose keeps first-frame viewpoint and framing; it keeps the *meanings* (those move upstream to whoever authors the trajectory, along with the need for this subject's vocabulary); and it gains an obligation to describe **off-screen** material, which inverts the text-driven rule that describing what the camera never sees is wasted budget.
- Cheap because the source shipped both sides: one lab, two prompt writers released together, opposite instructions, no fetch needed. Diff the sibling instructions first in any multi-project research release.
