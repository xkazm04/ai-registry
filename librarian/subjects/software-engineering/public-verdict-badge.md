# public-verdict-badge

Touched by [[2026-09-08-awesome-gpt-6-astra-games]], a repository run whose showcase
site stated one rule this subject's `outcome-branched-cache` had left implicit:
**a response served from the origin's own cache advises the tier in front with
its remaining lifetime, never a fresh interval**, and a stale or fallback answer
advises `no-store`. Landed as a boundary subsection under "Layers, and who
obeys you", corroborated by RFC 9111 `Age` / `current_age` (the standard's own
arithmetic, which the source re-implements because its edge tier ignores
`Age`), and bounded: immutable, content-addressed entries have no age worth
subtracting.

**Currency, same run.** All three applications here cite a feature the
project removed on 2026-08-29; each now carries the removal, the historical
commit to read the citations at, and `verified_on: 2026-09-08`. The removed
realization also carried the new boundary's gap - a fifteen-minute report
cache under a fixed ten-minute directive with no `Age` - and the
`node--outcome-branched-cache` application records that as its structural
fact. The subject therefore has **no live realization in the fleet**; its next
application must come from a project that grows a public artifact endpoint
again. Return when one does.
