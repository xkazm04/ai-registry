First touch: [[2026-08-30-1]], scoped `/deepen` under the librarian sweep. Ranked #9 (35
points) on the corrected worklist — and **the cleanest demand signal in the batch**: its

## New technique: `child-observed-posture` (7 techniques)

Three-lane convergence — a measured consumer deviation (2026-08-27), a live experiment,
and a reproduction.

**Every promise the transport makes is a promise about a *child*, and the host's view of
it fails silently at three seams: argv, environment, existence.** Anchored on
`gate-sees-target` — the host is checking a proxy for the thing it means to check.

## Refuted, and the method is the point

- **"No tool ships an overall wall-clock flag."** Refuted **as an absolute** while
  *confirmed* for the three local tools and roughly eleven mainstream ones. At least one
  newer tool applies a multi-minute ceiling **by default**, which truncates runs on the
  tool's clock and reads to the operator as a bad answer. The correction is a scope
  correction, not a reversal — the right shape.
- **"The only OS-enforced read-only stance in the fleet."** Refuted: a second is OS-level
  too, but **conditional on a runtime being installed or compiled**. The technique now
  states enforcement class as a fact about the machine, not about the release.
- **"This tool documents no plan/read-only flag."** Refuted — the flags have existed
  since 2026-01-16. The page had recorded **an absence with no witness**, which is this
  corpus's own `unknown-is-not-a-value` failure committed by a document that cites the
  law. The most instructive of the four.
- **The documented unattended-edit invocation.** Refuted **live**: the flag errors as an
  unexpected argument on the very version the page claimed.

## Confirmed and sharpened

- A metered key silently nulls the subscription field while the auth-method and provider
  fields stay clean — so the obvious probe reads healthy on exactly the rows that leak.
- **Credential-file existence proves nothing.** Second vendor sighting: this machine
  holds live credentials for an individual tier retired 2026-06-18, and the repo carries
  no deprecation notice. A dead tier with a live credential file is indistinguishable
  from a working one by inspection.
- Three envelope dialects, stream hygiene, and no timeout on the local tools — unchanged.

## Version-witness discipline under pressure

Two new applications on previously uncovered stacks. The judgment worth recording:
`claude-code--output-normalization` moved `verified_on` to today but **deliberately left
`verified_against` at the older version**, because the envelope smoke was not re-run.
That is rkb-profile §3.1 applied exactly — only something that has read the tree at a
version may claim it — and a worker did it unprompted, on a field nobody would have
audited.

## Blind lane vs web lane

Agreed on envelope dialects, both sandbox mechanisms, and the protocol's identity.
Diverged on one *current* fact: the blind lane had no knowledge of the 2026-06-18 tier
retirement and **would have landed a page recommending a dead transport**. The web lane
won, as briefed. This is the clearest demonstration in the batch of why the blind lane is
a calibration control and not an oracle.

## Cross-subject proposals

- **`subprocess-lifecycle` / `spawn-contract`** — the generic mechanic behind seam 1 is
  theirs: under shell concatenation a **zero-length argument is deleted** and its flag
  then consumes the next flag. `spawn-contract` warns about the shell path for quotes,
  spaces and dash-values, but not this.
- **`subprocess-lifecycle`** — through a shell, a missing binary is **not** a spawn
  error and the error event never fires. That contradicts the natural reading of
  `spawn-contract`'s "honestly reporting when they close".
- **New-subject lead: a bidirectional agent session protocol.** JSON-RPC over stdio, its
  own org, a v2 draft dated 2026-07-20, roughly fifty agents including every tool in this
  subject. It occupies the same architectural slot as print-mode spawning but is a
  *stateful bidirectional session* — mid-run permission callbacks, mode changes,
  cancellation, resume. Too big for this subject; likely a sibling under `runtime-and-io`.
  One vendor's experimental server is the same drift from another direction. **Return
  condition:** a second independent implementation reaching v2, or a connected project
  adopting one.
