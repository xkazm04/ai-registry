## Open leads

  for assessment contexts, argued well, and cross-bundle links are forbidden - so the
  boundary condition is stated in prose on this side rather than as a citation. If a third
  bundle ever meets the same split, this is the precedent for how it was handled: name the
  discriminator, do not link.

  argument is not specific to wizards; it applies anywhere an agent asks a human to
  decide. If `hitl-approval`'s review flow is ever deepened, check whether the same rule
  belongs there.
